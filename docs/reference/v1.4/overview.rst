Overview
########

The heart of the LimeSDR-USB board is Altera Cyclone IV (`EP4CE40F23C8N`_) FPGA. Its main function is to transfer digital data between LMS7002M RF transceiver and the PC through a USB 3.0 connector. The block diagram for LimeSDR USB board is presented in the Figure 3.

.. figure:: /images/LimeSDR-USB_1v4_diagrams_BD.png
  :width: 600

  Figure 3: LimeSDR USB v1.4 board block diagram

This section contains component location description on the board. LimeSDR USB v1.4 board picture with highlighted connectors and main components are presented in Figure 4 and Figure 5, respectively.

.. figure:: /images/LimeSDR-USB_1v4_components_top.png
  :width: 600

  Figure 4: LimeSDR USB v1.4 board top connectors and main components

.. figure:: /images/LimeSDR-USB_1v4_components_bot.png
  :width: 600

  Figure 5: LimeSDR USB v1.4 board bottom connectors and main components
